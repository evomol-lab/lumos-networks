                        The Arithmancy Pathway Profiler runs over-representation analysis (ORA) against an
                        explicit background: by default every gene tested in the source. Up- and
                        down-regulated genes are queried separately by default. Speedrichr is used first; if it is
                        unavailable, Lumos applies the same one-sided hypergeometric test to the Enrichr libraries locally.
                        Direction labels describe the input lists; ORA does not show that a pathway is activated.
